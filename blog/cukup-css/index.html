Bagi Saya itu Cukup dan Itu Sudah Bagus

“Our task is to simplify things. But simplifying things is not that simple”

~ Pak Mul, CEO Icube.Inc

Saya jadi teringat nasihat Pak Mul, owner salah satu perusahaan pengembang web e-commerce tempat saya bekerja dulu. Saat itu saya menganggapnya cuma quote motivasi biasa aja. Beberapa tahun setelah tidak lagi di sana, saya baru benar-benar merasakannya. Saya ternyata butuh sesuatu yang sederhana. Tapi untuk mendapatkannya, tidak sesederhana itu.

Mencari sesuatu yang benar-benar cocok dengan keinginan saya, ternyata sangat menyiksa. Tidak semua yang kita inginkan tersedia, dan kalaupun ada, pasti akan butuh penyesuaian yang memakan energi banyak.

Dengan naluri “ketidakpuasan” manusia, kita sering mencari banyak hal demi menemukan kecocokan yang pas dengan diri kita. Tanpa sadar, waktu kita habis untuk mencari daripada menikmati.

Saya hanya butuh yang cukup

Saya mantan backend programmer, saat ini aktif menjadi tech educator yang menulis dan berbagi tentang dasar-dasar pemrograman serta pemahaman umum tentang teknologi.

Sebagai seorang backend, urusan tampilan bagi saya adalah nomor ke-sekian. Prioritas utama saya selalu dua hal, aplikasi bekerja normal dan hasilnya sesuai harapan. Dua hal itulah titik kepuasan saya sebagai programmer. Tampilan dan desain baru saya perhatikan setelah dua syarat itu terpenuhi.

Saya sadar ini mungkin terdengar tidak profesional bagi sebagian orang. Tetapi dengan segala keterbatasan, saya hanya sanggup mengerjakan satu hal dalam satu waktu. Saya butuh ruang fokus yang besar sampai dua prioritas itu beres, baru bisa memikirkan yang lain. Meminjam ungkapan Linus Torvalds, “Saya sedang tidak meminta untuk dimaklumi, tapi hanya sedang menjelaskan siapa saya.” Memang beda konteks, tapi kalimat itu mewakili apa yang sulit saya ungkapkan.

Awalnya, di tengah ramainya komunitas yang melahirkan karya dengan tampilan memukau, saya justru memilih Bootstrap untuk beberapa proyek. Banyak yang menyarankan, “Pakai Tailwind saja, bro. Lebih modern dan keren.” Namun, saya tidak tertarik untuk hanya sekadar mengejar kesan modern. Bagi saya, “bagus” dan “keren” itu soal selera dan perspektif. Prioritas saya sederhana, tampilan website rapi dulu, urusan lain belakangan.

Belakangan, saya menemukan Pico CSS dan mulai memakainya di beberapa proyek terbaru, termasuk blog pribadi saya versimalik.com. Pico CSS menjawab kebutuhan “kesederhanaan” saya. Setelah mencoba beberapa classless framework lainnya, saya rasa Pico CSS paling pas untuk saat ini.

Namanya juga manusia

Meskipun Pico CSS sudah sangat membantu, masih ada kelemahan saya yang belum teratasi, yaitu memilih warna. Saya tidak paham bagaimana warna harus dipilih dan dipadukan. Saya bisa merasakan kalau sebuah tampilan warnanya tidak enak dilihat, tapi tidak tahu solusi alternatifnya. Sebaliknya, untuk website dengan warna yang bagus, saya juga tidak bisa menjelaskan kenapa bagusnya.

Selain itu, Pico yang sederhana masih menyisakan satu kebutuhan yang belum terpenuhi: sistem grid. Pico sebenarnya punya grid bawaan, tetapi tidak sefleksibel yang saya inginkan untuk merapikan tata letak.

Cukup.css

Dari masalah-masalah itu, saya butuh solusi nyata yang setidaknya bisa saya pakai sendiri, tanpa pusing lagi mencari framework punya siapa yang cocok. Akhirnya saya mencoba menggabungkan kesederhanaan Pico CSS dengan utility Bootstrap yang saya butuhkan, salah satunya sistem grid.

Berbekal kemampuan dasar CSS dan keinginan menyelesaikan masalah sendiri, saya minta AI membantu mengurai masalah itu dan menerjemahkannya ke styling CSS yang saya butuhkan.

Saya beri nama Cukup.css. Jujur, saya bingung mau memberi nama apa. Saya juga sedang tidak mau sok kebarat-baratan soal penamaan produk, saya cuma ingin produk ini mudah dipahami, bukan sekadar terlihat keren. Tujuannya memang sederhana begini.

Cukup.css lahir dari masalah yang saya alami sendiri, dari kelemahan yang saya miliki, dan untuk saya pakai sendiri. Sistem desain ini mengedepankan kesederhanaan dan utility yang biasa saya butuhkan untuk membangun tampilan website sederhana.

Karena bagi saya, indah atau kerennya sebuah tampilan itu relatif, tapi tampilan yang rapi, bersih, dan konsisten itu absolut. Bagi saya itu cukup, dan itu sudah bagus.

Ke mana setelah ini

Ke depannya, saya merencanakan beberapa fitur dan kelengkapan yang saya adaptasi dari framework lain, dengan melihat kebutuhan esensial sebuah tampilan website. Supaya tidak keluar dari filosofi framework ini, dan tidak keluar dari yang saya yakini, Fundamental Over Hype.

Walaupun project ini untuk dipakai sendiri, teman-teman juga bisa mencobanya. Aksesnya di GitHub, github.com/versimalik/cukupcss. Untuk melihat contoh pemakaian dan referensi kelas-kelas yang tersedia, saya juga sedang menyiapkan halaman dokumentasi resmi di versimalik.com/produk/cukupcss/demo. Namun, sejujurnya halaman itu masih dalam proses pengerjaan. Saya memilih merilisnya secara bertahap karena saya tidak ingin terburu-buru menyajikan sesuatu yang belum benar-benar saya pakai dan uji sendiri.

Saya tidak akan memaksa siapa pun untuk beralih ke Cukup.css, apalagi mengklaim ini lebih baik dari framework lain. Ini hanya alat yang saya buat agar saya bisa berhenti mencari-cari dan mulai menikmati proses membangun. Jika ada dari kalian yang merasakan kegalauan yang sama, lelah mengejar standar orang lain, dan hanya butuh sesuatu yang cukup, maka Cukup.css mungkin juga bisa menjadi teman perjalanan kalian.

Saya juga sadar, Cukup.css tidak akan pernah sempurna. Dan mungkin itulah yang membuatnya tetap manusiawi. Sama seperti saya, yang masih terus belajar, masih sering bingung memilih warna, dan masih sering merasa tidak cukup di tengah lautan karya orang lain. Tapi selama saya masih bisa membangun sesuatu yang rapi, bersih, dan konsisten. Selama itu saya bisa menikmati prosesnya, maka bagi saya itu cukup.

Dan itu sudah bagus.
